\section{Introducción}
% =============================================================================

El etiquetado gramatical (\textit{Part-of-Speech Tagging}, POS Tagging) es una tarea
fundamental en el procesamiento de lenguaje natural (PLN) que consiste en asignar
a cada token de una oración su categoría morfológica correspondiente, por ejemplo,
sustantivo, verbo, adjetivo o determinante. Formalmente, dado un vocabulario de
palabras y un conjunto finito de etiquetas gramaticales, el objetivo es encontrar la
secuencia de etiquetas $\hat{Y}$ que maximice la probabilidad condicional:

\begin{equation}
    \hat{Y} = \underset{Y}{\mathrm{argmax}}\; P(Y \mid X,\, \theta)
\end{equation}

\noindent donde $X = (x_1, x_2, \ldots, x_T)$ es la secuencia de entrada y
$\theta$ representa los parámetros aprendidos por el modelo.

En este taller se implementan y comparan tres arquitecturas de aprendizaje profundo
diseñadas para la tarea de POS Tagging en español: la \textbf{BiLSTM base},
la \textbf{BiLSTM-Deep} y la \textbf{BiLSTM-CRF}. Para ello se emplean dos
corpus de referencia, \textit{Ancora} y \textit{CoNLL2002}, utilizando el
\textit{framework} PyTorch. A lo largo del informe se describe el proceso de
preprocesamiento de los datos, la arquitectura de cada modelo, el diseño
experimental con búsqueda de hiperparámetros, y los resultados obtenidos. El
análisis comparativo busca evidenciar el impacto de añadir capas densas
intermedias y la capa CRF en el desempeño del etiquetador.

\section{Marco Teórico}

\subsection{Redes LSTM Bidireccionales (BiLSTM)}

Las redes de memoria a largo y corto plazo (\textit{Long Short-Term Memory},
LSTM) son un tipo de red neuronal recurrente diseñada para capturar dependencias
a largo plazo en secuencias. Una BiLSTM procesa la secuencia en ambas
direcciones —de izquierda a derecha y de derecha a izquierda— concatenando las
representaciones ocultas de ambas direcciones, lo que permite capturar contexto
tanto previo como posterior a cada token.

\subsection{Campos Aleatorios Condicionales (CRF)}

Los Conditional Random Fields (CRF) son modelos probabilísticos discriminativos
diseñados para tareas de etiquetado estructurado donde las salidas forman una
secuencia depediente. A diferencia de los Hidden Markov Models (HMM),
los CRF modelan directamente la probabilidad condicional $P(Y \mid X)$:

\begin{equation}
    P(Y \mid X) = \frac{1}{Z(X)} \exp\!\left(\sum_{k} \lambda_k F_k(Y, X)\right)
\end{equation}

\noindent donde $F_k(Y,X)$ son funciones de características, $\lambda_k$ son los
parámetros aprendidos, y $Z(X)$ es la función de partición que garantiza que la
distribución sea válida:

\begin{equation}
    Z(X) = \sum_{Y'} \exp\!\left(\sum_{k} \lambda_k F_k(Y', X)\right)
\end{equation}

Al combinar la BiLSTM con una capa CRF, el modelo puede modelar transiciones
globalmente coherentes entre etiquetas, lo cual resulta especialmente útil en
español dada el contexto morfológico del idioma.

\subsection{Arquitecturas a comparar}

Las tres arquitecturas evaluadas son:

\begin{enumerate}[leftmargin=*, label=\arabic*.]
    \item \textbf{BiLSTM Base}: Bidirectional LSTM seguida de una capa lineal de
          clasificación. Constituye el modelo de referencia.
    \item \textbf{BiLSTM-Deep}: Extiende el modelo base añadiendo capas densas
          intermedias con activaciones no lineales entre la BiLSTM y la capa de
          salida, incrementando la capacidad de representación.
    \item \textbf{BiLSTM-CRF}: Combina la BiLSTM con una capa CRF para modelar
          explícitamente las dependencias entre etiquetas consecutivas.
\end{enumerate}

\section{Preprocesamiento de los Datos}
% =============================================================================

\subsection{Construcción de oraciones y vocabulario}

El pipeline de preprocesamiento sigue los pasos estándar para garantizar la
comparabilidad entre experimentos. Las oraciones se construyen agrupando tokens
por identificador de oración y se truncan a \texttt{MAX\_LEN = 50} tokens. El
vocabulario se construye contando frecuencias y filtrando palabras con menos de
\texttt{MIN\_FREQ = 3} apariciones; las palabras fuera de vocabulario se mapean al
token especial \texttt{<UNK>}.

\end{lstlisting}

\subsection{Vectorización y Padding}

Las secuencias de palabras y etiquetas se convierten a matrices numéricas
aplicando padding de ceros hasta la longitud máxima definida. Esto permite
procesarlas en lotes uniformes (\textit{batches}) dentro de PyTorch.


\subsection{Partición de los Conjuntos}

Para Ancora se realiza una división aleatoria estratificada en los conjuntos de
entrenamiento (70\%), validación (15\%) y prueba (15\%). Para CoNLL2002 se
respetan las particiones oficiales del \textit{shared task}.

\section{Definición de los Modelos}
% =============================================================================

\subsection{BiLSTM Base}

% ── Describe brevemente la arquitectura y pega el código del modelo ───────────
El modelo base consiste en una capa de \textit{embedding}, una BiLSTM de una
sola capa y una capa lineal de clasificación que proyecta las representaciones
ocultas al espacio de etiquetas.

\subsection{BiLSTM-Deep}

La variante profunda añade una segunda capa LSTM y \textit{dropout} interno para
regularización, incrementando la capacidad no lineal del modelo entre la LSTM y
la salida.

\subsection{BiLSTM-CRF}

% ── Describe brevemente el modelo BiLSTM-CRF ─────────────────────────────────
La arquitectura BiLSTM-CRF reemplaza la capa lineal final por una capa CRF que
modela las transiciones entre etiquetas. Esto permite que el modelo aprenda
restricciones globales sobre secuencias válidas de etiquetas POS, mejorando la
coherencia de las predicciones.
